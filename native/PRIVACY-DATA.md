# 다루는 자료 — App Store 제출용 정리

개인정보처리방침 전문은 이 문서가 아니다. **앱이 실제로 무엇을 들고,
어디로 보내고, 언제 지우는지**를 코드 기준으로 적어 둔 것이다.
제출 화면(App Privacy)의 칸을 채울 때 여기서 옮겨 적는다.

무엇을 적었는지가 바뀌면 **이 문서도 같이 고친다.** 코드와 어긋나면 이 문서가 틀렸다.

---

## 1. 무엇을 들고 있나

| 자료 | 어디에 | 언제 나가나 | 무엇에 쓰나 |
|---|---|---|---|
| 주간 항목·요일 메모·취소선 | 기기 (App Group 컨테이너) | **로그인 + 메일 인증 + 구매**를 모두 마친 뒤에만 서버로 | 기기 사이를 맞추기 |
| 이메일 주소 | Firebase Authentication · 기기 키체인 | 로그인·인증 때 Firebase로 | 계정을 알아보기 |
| 비밀번호 | **어디에도 저장하지 않는다** | 로그인 그 순간 Firebase로 | 로그인 |
| 갱신 토큰(refresh) | 기기 키체인 (`expo-secure-store`) | 나가지 않는다 | 다시 열 때 로그인 유지 |
| 구매 여부 | 기기 (App Group) · 애플 | 나가지 않는다 (영수증을 우리 서버로 보내지 않는다) | 잠긴 자리를 여는 데 |
| 고른 말(ko/en)·소리 끔·안내 닫음 | 기기 | 나가지 않는다 | 화면 설정 |
| 캘린더 일정 제목·날짜 | 받아만 온다 | **나가지 않는다** (한 방향) | 주간표에 펼쳐 보기 |

**행동로그·분석·광고 식별자는 없다.** 웹 쪽에 만들어 둔 행동로그는 꺼져 있고
(`LOG.enabled = false`), 네이티브에는 옮기지 않았다.

## 2. 어디로 가나

| 받는 곳 | 무엇을 | 왜 |
|---|---|---|
| Firebase Authentication (Google) | 이메일·비밀번호·토큰 | 로그인과 메일 인증 |
| Cloudflare (Pages Functions · KV · Durable Objects) | 주간 자료 | 기기 사이 맞추기 |
| Firebase Firestore (Dada Calendar) | **읽기만** — 내 uid 아래의 일정 | 캘린더에서 받아 오기 |
| Apple (App Store) | 구매 | 일회성 구매·복원 |

우리 서버는 **이메일을 열쇠로** 주를 맡아 둔다 (`week:<email>:<weekId>`).
글자의 내용은 서버가 읽지 않고 합치기만 한다.

## 3. 언제 지워지나

- `내 계정 → 전부 비우기` — 서버의 주를 전부 지운다. 다른 기기도 열면 비워진다.
- `내 계정 → 계정 삭제` — **서버의 주 → Firebase 계정 → 기기의 계정 정보** 순서로 지운다.
  - **이 기기에 적어 둔 주는 기본으로 남는다.** 계정을 지우는 것과 적어 둔 것을
    버리는 것은 다른 뜻이라고 보았다. 함께 지우려면 그 자리에서 체크한다.
  - 지운 표시(`graves`)는 60일 뒤 정리된다 (다른 기기가 되살리지 못하게 하는 표시).
- 앱 삭제 — 기기에 있던 것이 함께 사라진다. **구매는 애플이 들고 있어 복원된다.**

## 4. 제출 화면(App Privacy)에 무엇으로 적나

| 항목 | 답 | 비고 |
|---|---|---|
| Contact Info → Email Address | 수집함 · **앱 기능에 사용** · 사용자와 연결됨 | 계정 |
| User Content → Other User Content | 수집함 · 앱 기능 · 사용자와 연결됨 | 주간 항목·메모 |
| Purchases | 수집함 · 앱 기능 · 사용자와 연결됨 | 일회성 구매 |
| Identifiers | **수집 안 함** | 광고 식별자 없음 |
| Usage Data · Diagnostics | **수집 안 함** | 분석 도구를 넣지 않았다 |
| Tracking | **없음** | 다른 회사 자료와 잇지 않는다 |

**로그인하지 않고 쓰면 수집하는 것이 없다.** 그 상태의 앱은 기기 밖으로
아무것도 보내지 않는다 — 이 문장이 이 제품의 기본값이다.

## 5. 사람이 준비해야 하는 것 (DADA REQUIRED)

- 개인정보처리방침 **웹 주소** — App Store Connect가 링크 하나를 요구한다.
  위 1~4를 그대로 풀어 쓰면 된다. (문안 작성은 이번 코드 작업 범위 밖)
- 계정 삭제 경로의 안내 — 애플은 **앱 안에서** 계정을 지울 수 있어야 한다고 본다.
  `내 계정 → 계정 삭제`가 그 자리다. 심사 메모에 그 경로를 적어 둔다.
- 데이터가 저장되는 나라(Cloudflare·Firebase의 지역)는 방침 문안에서 밝힌다.
