# Clear Week — 네이티브 (React Native / Expo)

종이 주간 플래너를 그대로 옮긴 것. 한 주가 한 화면에 고정되고, 손으로 긋고,
그은 것은 그 자리에 남는다.

**작업 전에 `../clearweek-spec.md`와 `../HANDOFF-NATIVE.md`를 읽을 것.**
충돌하면 spec이 맞다. 이 문서는 **네이티브 구현**만 설명한다.

웹(`../index.html`)은 지우지 않았다 — **손맛 비교의 기준선이다.**

---

## 깨면 안 되는 규칙

1. **취소선은 삭제가 아니라 축적이다.** 그은 항목은 그 자리에 남는다.
   흐려지지도, 접히지도, 아래로 내려가지도 않는다.
   완료 항목을 숨기거나 정렬로 내리는 기능은 **영구히 만들지 않는다.**
2. **자동 이월 없음.**
3. **알림·태그·통계·다크모드 없음.** 여기서 통계는 사용자에게 보여 주는
   달성률·연속기록·점수다. **앱 화면에 숫자가 나타나는 순간 위반이다.**
4. **애매하면 넣지 말고 물어본다.**
5. **손그림으로 남는 것은 취소선 하나뿐.** 세로선은 없다 — 열은 여백으로 갈린다.
6. **손이 덜 가는 쪽이 옳다.** 칸 나누기가 자동인 이유, 펜 판을 미리 깔아 둔 이유.

## 구조 — 판단이 한 곳에만 있게

| 자리 | 무엇이 있나 |
|---|---|
| `src/core/constants.js` | **튜닝 손잡이 전부.** 손맛을 고치려면 이 파일만 연다 |
| `src/core/week.js` | ISO 주 계산. 웹·서버와 **같은 `weekId`**가 나와야 한다 |
| `src/core/model.js` | 데이터 모양과 손질. 전부 새 객체를 돌려준다 |
| `src/core/grain.js` | 획의 결 — **같은 시드는 같은 획.** 좌표를 저장하지 않는 근거 |
| `src/core/erase.js` | 지우개 판정(버킷). 손을 뗄 때의 결판이 여기 |
| `src/core/columns.js` | 칸이 몇 단으로 나뉘나 — 개수가 아니라 넘치는지를 본다 |
| `src/core/hit.js` | 어디를 짚었나. 웹의 `elementFromPoint` 자리 |
| `src/ui/layout.js` | **한 주의 자리를 통째로 계산한다.** 획 좌표와 손짓 좌표가 여기서 함께 나온다 |
| `src/ui/InkLayer.jsx` | Skia. 획만 그린다. 손짓은 안 받는다 |
| `src/ui/GestureSurface.jsx` | 손짓 전부. **긋는 동안 JS 스레드를 타지 않는다** |
| `src/ui/WeekGrid.jsx` | 글자. 재는 것은 글자 폭·줄 수뿐 |
| `src/ui/PenPad.jsx` · `Editor.jsx` | 펜으로 쓰기 / 탭해서 적기 |
| `src/store/storage.js` | **App Group 공유 UserDefaults**(iOS) / MMKV(그 외) |
| `src/store/widget.js` | 위젯에 넘기는 것 |
| `src/sync/rules.js` | 캘린더에서 받은 것을 어떻게 앉히나 — **규칙만** (검사 가능) |
| `src/sync/*.js` | Firebase 로그인 · 서버 · 캘린더 읽기 |
| `targets/widget/` | WidgetKit 위젯 (Swift). App Group으로만 통신한다 |
| `tools/make-sounds.mjs` | SOUND 값으로 wav를 굽는다. 값을 고쳤으면 다시 굽는다 |
| `tools/preview.mjs` | 자리를 SVG로 그려 본다. **기기 화면이 아니다** |
| `BUILD-STEPS.md` | 실기기까지 가는 단계 — 계정 화면 클릭 경로 포함 |

**합치기 규칙은 여기에 없다.** 서버 한 곳(`../functions/_lib.js`)에만 있다 —
두 곳에 두면 갈라지고, 갈라지면 무엇이 맞는지 아무도 모른다.

## 웹과 다르게 한 것 — 그리고 왜

| 웹 | 네이티브 | 왜 |
|---|---|---|
| 칸마다 SVG 하나 | **주간 표 전체에 Skia 판 하나** | 지우개가 칸·단을 넘어가야 한다. 판이 하나면 저절로 된다 |
| 브라우저가 자리를 잡고 `getClientRects()`로 되물음 | **`layout.js`가 자리를 정한다** | 되물음이 없다. 대신 획 좌표와 손짓 좌표가 **같은 계산에서 나와** 어긋날 수 없다 |
| Pointer 이벤트 → JS | **gesture-handler + worklet** | 긋는 동안 JS 스레드를 타면 획이 끊긴다 |
| Web Audio로 그때그때 합성 | **미리 구운 wav 둘** | 네이티브에 그 합성기가 없다. 굽는 값은 같다 |
| `navigator.vibrate` (iOS가 무시) | **`expo-haptics` — 실제로 된다** | 웹에서 못 하던 것 |
| `localStorage` | **App Group 공유 UserDefaults** | 위젯(Swift)이 읽어야 한다. 나중에 옮기면 마이그레이션이 생긴다 |
| refresh 토큰이 `localStorage` | **키체인(`expo-secure-store`)** | 네이티브에는 키체인이 있다 |
| 항상 깔린 투명 입력창 | **글자 아래에만 두는 `TextInput`** | 스크리블 함정은 그대로 온다 (HANDOFF §4-1) |

## 확정된 제스처

| 제스처 | 동작 |
|---|---|
| 요일 칸 **빈 곳** 탭 | 그 칸에 항목 추가 (＋ 버튼 없음) |
| **왼쪽 여백**(날짜와 그 아래) 탭 | 요일 아래 메모 |
| 항목 탭 | 편집 (**그어진 항목은 불가**) |
| 항목 위 가로 드래그 | 긋기 — 지나간 만큼만, 줄 단위 |
| **왼쪽 여백에서 시작해 가로로** | 그 높이의 항목을 긋는다 |
| 그어진 줄 위 좌우 문대기 | 지우개 — 문지른 자리만 벗겨짐. 넓게 문대면 칸·단을 넘어간다 |
| 항목 더블탭 | 남은 줄까지 자동으로 긋기 |
| 항목 롱프레스 0.5초 | 삭제 — 그대로 끌면 지나간 것 전부 |
| **펜을 빈 곳에 대고 그냥 쓰기** | 크게 적힌다 — 탭 없음 |
| 아무 데서나 아래로 당기기 | 새로 받기 |
| 머리말 스피커 / 사람 · 제목 롱프레스 | 소리 / 내 계정 |

**새 제스처를 넣기 전에** (가로/세로) × (그어짐/안 그어짐) × (항목/빈 곳/여백)
조합을 먼저 확인할 것. **칸 안 세로 드래그는 지금 비어 있다.**

## 돌리기

```bash
npm install
node tests/run.mjs          # 검사 110개. 기기도 브라우저도 필요 없다
node tools/make-sounds.mjs  # SOUND 값을 고쳤을 때만
node tools/preview.mjs p.svg # 자리를 눈으로 보고 싶을 때
npx expo export --platform ios   # 번들이 되는지 (문법·의존 확인)
```

실기기에 넣으려면:

```bash
eas device:create           # 기기 UDID 등록
eas build -p ios --profile device
```

**먼저 해야 하는 것 둘**
1. `app.json`의 `appleTeamId`를 실제 값으로. (개발자 계정 $99/년이 필요하다)
2. App Group `group.dev.clearweek`을 개발자 계정에서 만들고 앱·위젯에 붙인다.
   앱과 위젯이 만나는 자리는 여기 하나뿐이다.

## 실기기에서만 알 수 있는 것 — **아직 아무것도 확인되지 않았다**

이 목록은 사람이 폰에서 봐 준 것만 옮겨 적는 자리다. 지금은 비어 있다.
**"확인했습니다"라고 쓰지 말 것.**

봐 줘야 하는 것:

1. **긋는 손맛** — 웹보다 나은가. **여기서 갈린다. 아니면 그 뒤는 의미 없다.**
2. 지우개 — 넓게 문댔을 때 칸·단을 넘어가는지, 손 뗄 때의 결판이 자연스러운지
3. **애플펜슬 스크리블** — 펜을 빈 곳에 대고 썼을 때 탭 없이 들어가는지,
   그리고 **글자 위를 그은 것이 새 글자로 새지 않는지** (웹에서 가장 크게 밟은 함정)
4. 소리 — 사각사각과 톡의 균형(웹에서 맞춘 −4.5 dB가 그대로 왔는지),
   무음 스위치를 무시하는지, 껐을 때 남의 앱 소리를 놓아 주는지
5. 진동 — 웹에서 못 하던 것이라 기준이 없다. 세기가 맞는지
6. 자판이 올라올 때 표가 밀리지 않는지 (한 화면 고정이라 밀리면 끝이다)
7. 항목 높이 26 — 초안은 "긋기를 위해 44 양보 불가"였다. **여전히 미검증**
8. 위젯 — App Group으로 값이 실제로 건너가는지
9. 백업 — 공유 시트로 파일이 제대로 떨어지는지

## 아직 없는 것 / 알려진 것

1. **되돌리기 없음.** 롱프레스 삭제는 확인도 취소도 없다 (웹과 같다).
2. **로그인은 Firebase 그대로 뒀다.** spec §11은 "네이티브에서는 iCloud가
   계정 없이 맞춰 주므로 로그인이 통째로 사라져야 한다"고 적어 두었다.
   지금 Firebase를 유지한 이유는 **캘린더가 같은 계정이라 연동이 딸려 오기**
   때문이다. CloudKit으로 갈아탈지는 아직 결정하지 않았다 —
   갈아탈 때를 위해 `src/sync/`는 앱의 다른 곳에 뿌리를 내리지 않았다.
   **로그아웃 상태의 앱은 서버를 전혀 건드리지 않는다.**
3. **동시에 밀면 한쪽이 덮일 수 있다** (서버 KV에 조건부 쓰기가 없다).
   다음 차례에 스스로 회복된다. 근본 해결은 Durable Objects.
4. **행동로그는 옮기지 않았다.** 웹에서도 꺼 두었다 — 읽지 못하는 기록은
   남의 기기에서 도는 짐이다.
5. **글자 폭을 재는 것과 칸이 나뉘는 것이 서로를 부른다.** 나뉘면 글씨가
   작아지고, 작아지면 줄이 덜 감긴다. 지금은 잰 값을 그대로 쓴다 —
   경계에서 한 번 더 다시 그릴 수 있다. 실기기에서 떨림이 보이면 여기다.
